# FINOVA MVP 🚀

Este proyecto es el MVP (Minimum Viable Product) del frontend para FINOVA, generado inicialmente a través de las herramientas de IA de Figma (Figma Make) y optimizado para un entorno de desarrollo moderno y escalable.

## 🛠️ Stack Tecnológico

*   **Framework:** [React](https://react.dev/)
*   **Herramienta de Construcción:** [Vite](https://vitejs.dev/)
*   **Lenguaje:** [TypeScript](https://www.typescriptlang.org/)
*   **Estilos:** [Tailwind CSS](https://tailwindcss.com/)
*   **Gestor de Paquetes:** [pnpm](https://pnpm.io/)

---

## 💻 Requisitos Previos

Antes de ejecutar este proyecto, asegúrate de tener instalado en tu sistema:
*   [Node.js](https://nodejs.org/) (Versión 18 o superior recomendada)
*   **pnpm** (Si no lo tienes, puedes instalarlo ejecutando `npm install -g pnpm`)

---

## 🚀 Cómo levantar el proyecto en local

Sigue estos pasos para clonar, instalar las dependencias y ejecutar la aplicación en tu computadora:

1. **Clonar el repositorio:**

git clone [https://github.com/esmaigua/FINOVAMVP.git](https://github.com/esmaigua/FINOVAMVP.git)
cd FINOVAMVP

2. Instalar las dependencias:
Esto creará el entorno encapsulado (node_modules) necesario para el proyecto.

pnpm install
**Iniciar el servidor de desarrollo:**

pnpm run dev
**Ver la aplicación:**
Abre tu navegador web y dirígete a:
http://localhost:8443 (el puerto puede variar, revisa la salida de tu terminal).
